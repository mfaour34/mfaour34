## 🤖 Agentic workflows

What I'm good at when working with AI coding agents:

- **Multi-agent orchestration**: running many Claude Code sessions in parallel under a "conductor" session that monitors them, answers routine questions, and escalates real decisions to me over Slack.
- **Ticket-to-merge automation**: driving an epic of dependent Jira tickets as a DAG, with child agents picking up tickets, PRs monitored and merged on approval, and downstream work unblocked automatically.
- **Context engineering**: keeping long-running work in durable, git-backed context instead of giant chats, so a session can `/clear` and resume from a few thousand tokens.
- **Guardrails and review**: hooks, skills and checkpoints that keep agents on task, plus human review loops for agent-written specs and code.
- **Tooling for agents**: building and customizing the tools agents run on: session managers, hooks, skills, MCP servers.
